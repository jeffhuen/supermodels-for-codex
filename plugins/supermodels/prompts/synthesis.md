# Synthesis Guide

Codex owns synthesis after the providers complete their review phases.

For `review`, providers complete a blind first pass only. Synthesis must preserve independent attribution and must not imply provider-to-provider cross-examination happened.

For `adversarial-review`, providers complete the same blind first pass first. If at least two providers return usable structured output, each provider then challenges the other provider's first-pass review. Synthesis must include both first-pass results and cross-challenge results, with clear attribution.

Group results by:

- Consensus findings.
- Provider-specific findings.
- Disagreements or contradictory recommendations.
- Likely false positives or weakly supported claims.
- Overcomplication and non-surgical-change findings.
- Suggested next steps.

When cross-challenge is skipped because fewer than two usable provider outputs were available, state that limitation directly instead of presenting the run as a full adversarial exchange.
